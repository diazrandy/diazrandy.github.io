# Randy Díaz · Portfolio & Online Resume

Personal website: **[diazrandy.github.io](https://diazrandy.github.io)**

## About

Digital portfolio and interactive resume of a retail professional with 10+ years leading teams and stores (Zara, H&M, IKEA, adidas, Apple), based in Madrid. Focus: people, teams and results.

## Features

- Bilingual (ES/EN) with language switch and remembered preference
- 30-second summary: key figures, brands and a people-centred story ("How I work")
- Retail milestones (store openings), experience timeline and downloadable CV (ES/EN, PDF)
- Responsive, light/dark mode, print styles, accessible (keyboard focus, reduced motion)
- Subtle background of soft moving shadows (pure CSS)
- SEO: Open Graph, Twitter Card, JSON-LD (Person), sitemap and robots.txt

## Tech stack

HTML5 · CSS3 · vanilla JavaScript · GitHub Pages
